# ak74.pro — Фабрика модульных домов

Статический сайт: один `index.html`, все фото, шрифты и скрипты лежат рядом в этой же папке. Сборка не нужна.

## 1. GitHub
1. github.com → **New repository** → имя, например `ak74-site` → Create.
2. На странице репозитория: **Add file → Upload files**, перетащите **все файлы этой папки** (без самой папки) → **Commit changes**.

## 2. Vercel
1. vercel.com → войдите через GitHub → **Add New → Project** → выберите репозиторий `ak74-site` → **Import**.
2. Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми → **Deploy**.
3. Через минуту сайт откроется на адресе вида `ak74-site.vercel.app`.

## 3. Домен ak74.pro (Reg.ru)
1. Vercel → проект → **Settings → Domains** → добавьте `ak74.pro` и `www.ak74.pro`.
2. Reg.ru → ak74.pro → **Управление зоной DNS**:
   - запись **A** для `@` → `76.76.21.21`
   - запись **CNAME** для `www` → `cname.vercel-dns.com`
3. Через 1–24 часа домен заработает, SSL Vercel выпустит сам. На Тильде отвяжите домен, чтобы не было конфликта.

## 4. Заявки
Формы «Контакты» и «Отправить расчёт инженеру» отправляют письма на **blok.konteynery@bk.ru** через сервис FormSubmit (бесплатно, без сервера).
- После первой тестовой заявки на эту почту придёт письмо **«Activate Form»** — нажмите кнопку активации один раз. После этого заявки приходят сразу.
- Сменить почту: в `index.html` найдите строку `const LEAD_URL` и замените адрес.

## Обновления
Правки вносятся в исходник `AK74 Redesign.dc.html` в проекте, затем новый `index.html` загружается в репозиторий (Add file → Upload files, с заменой). Vercel обновит сайт автоматически.
